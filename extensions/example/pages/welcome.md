# Welcome

This page lives in the **sidebar**, like the views of Copilot or Dev
Containers in VS Code.

## What it is built with

Markdown. The header lines at the top set the title and the location:

```
---
title: Welcome
location: sidebar
---
```

Without `location`, a page lands in the editor area.

## What is possible here

- Headings, paragraphs, lists
- `Code` and code blocks
- [Links](https://example.com) that open in the system browser
- Images, quotes and tables

What is not possible: scripts. The page runs in a sandboxed frame without
JavaScript and without access to Lumen.
